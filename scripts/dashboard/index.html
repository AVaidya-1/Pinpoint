Your app team, in one window

  1. Configure the product once. Give your setup agent the full prompt in docs/USER_MANUAL.md. It installs this framework into your product checkout, records the goal and checks model access. The shipped example is only a demonstration.
  2. Talk to the Director. Ask a question for a read-only answer. Choose “Give direction and run” to steer or start authorized work. You never need to message the foremen or worker.
  3. Watch the dashboard. See task outcomes, active roles, provider waits, memory and handoffs. The product app uses its own localhost URL.
  4. Pause before shutdown. Pause team works without a live model response. Keep the machine awake until “Safe pause confirmed” appears. Closing this window does not stop the team.
  5. Review the result. Ask for the handoff and use the app yourself. Queue COMPLETE means all tasks and batch checks finished; read the completion report for live acceptance results.

Messages and evidence stay in this product's ignored runtime directory. GitHub saves source, not the complete runtime history. Continuous runs have no guaranteed completion time.
