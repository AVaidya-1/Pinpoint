### Step 2: Fixture generation
1. Create fixtures/generate.py that produces fixtures/generated/ containing:
   - A multi-page technical PDF (at least 5 pages) with:
     - Each page bearing a unique, machine-readable page marker string
       (e.g., "PAGE_MARKER_P3" on page 3) so that physical-page identity
       can be verified after noncontiguous selection, import, and display.
     - Page 1: A specification table with a known target row AND at least
       two plausible distractor rows with similar labels/units (section 15B).
     - Page 2: A chart/plot with labeled axes, legend, and a target curve
       region (section 15B).
     - Page 3: A raster-only flowchart with decision nodes and branches,
       no searchable text layer (section 15B).
     - Page 4: A connector/schematic diagram with repeated labels appearing
       on different sub-diagrams (section 15B).
     - Page 5: A simple geometric shapes page with known overlay targets
       at exact coordinates for geometry testing.
   - A portrait PDF page, a Rotate=90 landscape PDF page, and a PDF
     with non-default CropBox — each with a page marker and a known
     overlay target at documented coordinates.
   - An EXIF-oriented JPEG image with a known target region.
   - A standard PNG image with a known target region.
   All fixture coordinates are recorded in fixtures/development.json.
   Every generated page must have a distinguishable page marker.

2. Create fixtures/development.json with ground-truth coordinates for each
   fixture, including:
   - Fixture filename, page index, page marker string, and expected
     overlay target as `[x0, y0, x1, y1]` normalized 0-1 coordinates.
   - Expected rendered dimensions (width_px, height_px) for each page.

3. Create fixtures/holdout.json with 20 frozen evaluation questions per
   PRODUCT_BRIEF.md section 15B, structured as:
   - 4 text lookups targeting specific rows/paragraphs.
   - 4 table/label-and-unit lookups with nearby distractor rows.
   - 8 genuinely visual questions: flow direction, spatial relation,
     graphical branch, chart curve, unlabeled component.
   - 4 absent-answer questions with plausible distractors present.
   Each answerable question includes expected page ID (by marker),
   expected evidence region, and notes on what distinguishes the
   correct target from distractors. Truth derives from construction.
   The development set and holdout set must be explicitly separated
   with non-overlapping page IDs.

4. Run `C:/Users/vaidy/.local/bin/uv.exe run --project backend python fixtures/generate.py`
   and verify outputs exist in fixtures/generated/.

### Step 6: Independent validator
1. Create app_tools/validate_slice.py that independently verifies:
   - **Artifact existence**: every file listed in the artifacts array of
     report.json exists on disk. Produces `artifacts_missing: []` or a list.
   - **Byte preservation**: for each imported document, independently compute
     SHA-256 of the stored original file AND of the original fixture input;
     compare. Produces `hash_pairs: [{fixture, stored, match: bool}]`.
   - **Overlay alignment**: for each fixture with known coordinates, load the
     rendered canonical raster, compute the expected overlay rectangle in
     pixel coordinates from the known normalized coords, and measure
     alignment error as max absolute pixel offset between expected and
     actual overlay bounds (from the test overlay data). Produces
     `alignment_results: [{fixture, view, expected_px, actual_px, error_px, pass: bool}]`
     with a tolerance of 2px at each zoom level (Fit, 100%, 200%).
   - **Rotation/CropBox/EXIF**: load each special fixture, verify rendered
     dimensions match expected orientation-corrected dimensions within 1px.
     Verify page marker text matches expected page. Produces
     `orientation_results: [{fixture, expected_dims, actual_dims, marker_match, pass: bool}]`.
   - **Physical-page identity**: for a noncontiguous page import (e.g.,
     selecting pages 2 and 4 from a 5-page PDF), verify that stored metadata
     records correct physical page numbers AND that rendered images contain
     the correct page markers. Produces
     `page_identity_results: [{doc, selected_pages, stored_pages, markers_found, pass: bool}]`.
   - **Holdout structure**: verify fixtures/holdout.json contains exactly
     20 questions with the 4/4/8/4 split, each answerable question has
     expected_page and expected_region, and development/holdout page sets
     are disjoint. Produces `holdout_valid: bool, holdout_errors: []`.
   - Overall: `validator_pass: bool` (true iff all subsections pass).
   Write results to `out/orchestration/import-viewer/validation.json`.
2. Run `C:/Users/vaidy/.local/bin/uv.exe run --project backend python app_tools/validate_slice.py`.
